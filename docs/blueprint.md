# **App Name**: ScriptVision AI

## Core Features:

- Script Upload and Parsing: Allow users to upload script files (doc, pdf) and automatically parse the script to identify scenes and their order.
- Scene Extraction via AI: Utilize an AI agent to automatically extract scene descriptions and metadata from the uploaded script, ensuring accurate scene segmentation.
- Storyboard Sketch Generation: Automatically generate a storyboard sketch for each scene using a generative AI tool, providing a visual representation of the script.
- Image Selection and Enhancement: Allow users to select individual sketches and enhance them using a ComfyUI workflow via API to create detailed, ultra-realistic images.
- Animation Generation: Enable users to select two keyframes and generate animated transitions between them using ComfyUI workflows, visualizing scene dynamics.
- Asset Download: Provide options to download individual images or animations, as well as the entire project with all drawings, detailed images, and animations.
- Tabbed Organization: Organize drawings, detailed images, and animations into separate tabs for easy access and management.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to convey creativity and sophistication.
- Background color: Light grey (#F0F0F0), offering a neutral backdrop.
- Accent color: Soft lavender (#E6E6FA) for a subtle highlight that complements the primary color.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for headlines or body text
- Left sidebar for scene list, main content area for storyboard and detailed image display, and tabbed interface for organizing assets.
- Use a consistent set of icons representing actions like upload, download, enhance, and animate, providing visual cues for user interactions.
- Use subtle transitions and animations to enhance the user experience without being distracting.
